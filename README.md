# Контрольная точка №1 — Маршрутизация. Layout

Проект Next.js с демонстрацией файловой маршрутизации, Layouts и Templates.

## Выполненные требования

-  Статические маршруты `/about` и `/blog` с корректными `page.tsx`
-  Динамические сегменты `[id]` и вложенный `[commentId]` с типизацией `params` (Promise в Next.js 15+)
-  Навигация через `<Link>` с подсветкой активной ссылки (`usePathname`)
-  Демонстрация разницы между `layout.tsx` (сохраняет состояние) и `template.tsx` (перемонтируется)
-  Раздел «Курсы» с собственным layout и динамической страницей `[id]`
-  Программный переход через `useRouter`

## Как запустить

```bash
npm install
npm run dev
